# Comparative Models for Heart Disease Prediction

Reproducible computational analysis accompanying the doctoral thesis and scientific article on the comparative evaluation of logistic regression, Random Forest, and Gradient Boosting models for heart disease prediction using the Cleveland Heart Disease Dataset.

## Overview

This repository contains the computational workflow used to support the comparative analysis of predictive models presented in the doctoral thesis and the related scientific article.

The analysis evaluates:

* Logistic Regression
* Random Forest
* Gradient Boosting

The computational workflow includes predictive performance evaluation, sensitivity, specificity, ROC AUC, calibration, stability analysis, repeated stratified cross-validation, statistical inference, and evaluation on an independent test set.

The repository is intended to support computational reproducibility and provide access to the analytical workflow associated with the corresponding scholarly outputs.

## Methods

The computational workflow evaluates the comparative performance of statistical and machine-learning models for heart disease prediction.

The analysis includes:

1. Data preparation and preprocessing.
2. Model training.
3. Repeated stratified cross-validation.
4. Predictive performance evaluation.
5. Sensitivity and specificity analysis.
6. ROC curve and AUC analysis.
7. Calibration assessment.
8. Stability analysis.
9. Statistical comparison of model performance.
10. Evaluation using an independent test set.


## Models

The repository implements the following predictive approaches:

* Logistic Regression
* Random Forest
* Gradient Boosting

The purpose is not to assume that greater algorithmic complexity necessarily produces superior predictive performance, but to evaluate the competing approaches empirically under a consistent validation framework.


## Dataset

The analysis uses the Cleveland Heart Disease Dataset.

The repository contains the computational workflow associated with the analysis. Users should consult the doctoral thesis and scientific article for the methodological description, dataset provenance, preprocessing decisions and interpretation of the results.
